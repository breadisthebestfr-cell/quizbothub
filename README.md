# quizbot

## Features
- 90 quiz categories across easy, medium and hard difficulty
- Quiz, Kahoot, Sudden Death and Team modes
- Streak bonuses, skip voting, hints, autoplay
- Leaderboard, history, stats, server hop
- Anti-AFK, troll mode, double points, bonus questions
